# ZIMA-TALK — универсальный AI-секретарь для Telegram

Бот-секретарь «Foxy» 🦊 на базе Claude (Anthropic), который отвечает на сообщения
в ваших личных чатах через **Telegram Business** и помогает владельцу аккаунта:
принимает обращения, записывает на встречи, создаёт задачи и напоминания.

## Для чего нужен бот

Бот подключается к вашему Telegram-аккаунту (через Telegram Business) и выступает
вашим виртуальным секретарём: пока вы заняты, он вежливо отвечает собеседникам,
выясняет суть вопроса, собирает детали и передаёт всё вам. Вы при этом управляете
ботом прямо из переписки — командами и инструкциями на естественном языке.

## Возможности

**Для собеседников (клиентов):**
- Автоответы на русском, английском и тайском — язык определяется автоматически
- Распознавание голосовых сообщений (Whisper) с показом текста и ответом
- Анализ фото с подписью (Claude Vision)
- Тёплое приветствие новых контактов, узнавание постоянных
- Молчание в ответ на «Спасибо», «Ок» и прочие реплики, не требующие ответа

**Для владельца (команды пишутся прямо в чате с клиентом, ответы приходят вам в личку):**
- `/task [текст]` — извлечь задачу из последних сообщений (или из текста) и сохранить в Notion
- `/calendar [текст]` — извлечь встречу из переписки и создать событие в Google Calendar
- `/summary` — краткое резюме переписки
- `/draft <направление>` — черновик ответа клиенту («/draft вежливо откажи»)
- `/find <имя>` — поиск по контактам
- `/note <текст>` — заметка к чату (бот учитывает её в ответах)
- «напомни через 30 минут …» — напоминание в личку
- Любое сообщение с ключевыми словами «запомни», «добавь», «новое правило» и т.п.
  сохраняется как постоянная инструкция для бота

**Команды в личном чате с ботом:**
- `/start` — сброс истории и приветствие
- `/clear` — очистить историю чата
- `/reminders` — список активных напоминаний

**Безопасность:**
- Rate limiting (20 сообщений/мин на чат) с алертом владельцу
- Детектор prompt-инъекций и попыток выудить данные (RU/EN) с алертом владельцу
- Бот не раскрывает системный промпт, контакты и переписки других клиентов
- Команды владельца работают только с его Telegram ID (`OWNER_CHAT_ID`)

## Установка (macOS)

Требования: Python 3.10+, [Homebrew](https://brew.sh), ffmpeg (для распознавания голосовых).

```bash
# 1. Зависимости системы
brew install python ffmpeg

# 2. Клонировать репозиторий
git clone https://github.com/jahrider/zima-talk.git
cd zima-talk

# 3. Виртуальное окружение и пакеты
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 4. Конфигурация
cp .env.example .env
# откройте .env и заполните TELEGRAM_BOT_TOKEN, ANTHROPIC_API_KEY, OWNER_CHAT_ID

# 5. Запуск
python bot.py
```

Без переменной `WEBHOOK_URL` бот работает через long polling — публичный IP,
порты и сертификаты не нужны, подходит для локального запуска.

## Настройка

### 1. Telegram-бот
1. Напишите [@BotFather](https://t.me/BotFather) → `/newbot` → получите токен → в `.env`.
2. Узнайте свой ID у [@userinfobot](https://t.me/userinfobot) → `OWNER_CHAT_ID` в `.env`.

### 2. Telegram Business (чтобы бот отвечал в ваших личных чатах)
Нужна подписка Telegram Premium:
**Настройки → Telegram Business → Чат-боты** → укажите вашего бота и выберите,
в каких чатах он работает. Без этого бот отвечает только в личном чате с ним.

### 3. Anthropic API
Ключ создаётся на [console.anthropic.com](https://console.anthropic.com/) → `ANTHROPIC_API_KEY`.

### 4. Notion (опционально — для задач)
1. Создайте интеграцию на [notion.so/my-integrations](https://www.notion.so/my-integrations) → `NOTION_TOKEN`.
2. Создайте базу задач со свойствами: `Name` (title), `Статус` (select),
   `🔥 Приоритет` (select), `Контекст` (multi-select), `⏱ Время` (select),
   `🗓 Дата` (date), `Комментарий` (rich text).
3. Дайте интеграции доступ к базе и укажите её ID в `NOTION_DATABASE_ID`.

### 5. Google Calendar (опционально — для /calendar)
Получите OAuth-токен с правом `https://www.googleapis.com/auth/calendar`
и сохраните его как `google_token.json` в каталоге данных (`data/` по умолчанию).

## Эксплуатация

1. Запустите бота (`python bot.py`) — он начнёт отвечать в подключённых чатах.
2. Клиенты пишут вам как обычно — бот отвечает сам, новых контактов приветствует.
3. Вы пишете в том же чате команды (`/summary`, `/task`, `/draft …`) —
   ответы приходят вам в личку, клиент их не видит.
4. Обучайте бота на ходу: «запомни: по ценам отвечай, что прайс вышлю лично» —
   правило сохранится и будет действовать во всех чатах.
5. Все данные хранятся в JSON-файлах в каталоге `data/`:
   `history.json` (переписки), `contacts.json`, `notes.json`,
   `instructions.json`, `reminders.json`, лог — `bot.log`.

### Запуск на сервере (webhook)
Задайте в `.env`:
```
WEBHOOK_URL=https://ваш-домен-или-IP:88/webhook
WEBHOOK_PORT=88
```
и положите `webhook.pem` / `webhook.key` (самоподписанный сертификат) в каталог данных.

### Полезно знать
- История каждого чата хранится по последним 20 сообщениям.
- Модель — `claude-haiku-4-5` (быстрая и дешёвая); меняется в `bot.py`.
- Часовой пояс — `BOT_TIMEZONE` (по умолчанию `Asia/Bangkok`).
- Whisper-модель `tiny` загружается при первом голосовом сообщении (~75 МБ).
